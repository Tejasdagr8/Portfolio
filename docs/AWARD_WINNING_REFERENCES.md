# Award-winning & legendary portfolio references

Curated list of famous, award-winning developer portfolios — separate from [`INSPIRATION.md`](./INSPIRATION.md) (which covers peer dev sites like Akshay, Krishna, Moonbucks).

**Use this doc to:** study craft at the top of the industry, borrow *principles* (not layouts), and know when spectacle is worth it vs when clarity wins for recruiters.

Live site: https://tejas-melkote.vercel.app/

| Column | Meaning |

| **Awards** | Awwwards SOTD, FWA, Webby, GSAP, etc. |

## Tier A — Legendary (industry benchmarks)

These are the names every “best portfolio” list cites. They set expectations for what “memorable” can mean.

### 1. Bruno Simon — creative developer

| | |
|---|---|
| **Live** | [bruno-simon.com](https://bruno-simon.com/) |
| **Legacy** | [2019 drive-a-car portfolio](https://github.com/brunosimon/folio-2019) (still referenced everywhere) |
| **Code** | [folio-2025 on GitHub](https://github.com/brunosimon/folio-2025) (MIT, incl. Blender assets) |
| **Awards** | **FWA of the Year 2025** + **FWA People's Choice 2025**; **Awwwards SOTD** (Jan 2026, ~8.11); **2× Webby 2026** (Technical Achievement + People's Voice) |

**Why it's legendary:** The portfolio *is* the demo. You explore a 3D world (drive, physics, secrets) instead of scrolling a PDF. Two generations of the site both went viral; the 2025 version documents the full stack (Three.js/TSL, Rapier, Howler) on-page.

**Steal for Tejas:**
- **Show skill through interaction** — you already do this with terminal, architecture diagrams, live embeds; double down on “using the site proves I build systems”
- **Easter eggs with purpose** — Konami, speed run, sound toggle are in the same spirit; tie each to a skill (agents, perf, UX)
- **Open-source the interesting parts** — Bruno’s MIT repo drives inbound for years; your pulse API + spotlight patterns could be a small OSS slice later

**Skip:**
- Full WebGL world — months of work, heavy mobile/perf cost, wrong signal for ML + production engineering roles unless you're targeting creative-tech only

### 2. Brittany Chiang — frontend engineer

| | |
|---|---|
| **Live** | [brittanychiang.com](https://brittanychiang.com/) |
| **Code** | [bchiang7/v4](https://github.com/bchiang7/v4) (~8k+ GitHub stars, most-forked dev portfolio) |
| **Awards** | Not a spectacle site — fame is **reach** (stars, forks, hiring copy everywhere) |

**Why it's legendary:** The anti-flash portfolio. Dark, minimal, **experience timeline as hero**, short about blurb, featured projects with context. Recruiters get answers in 30 seconds.

**Steal for Tejas:**
- **Work history before project grid** — you have Experience; make impact lines scannable (company · role · 2-line outcome)
- **Restraint in About** — 4 sentences beats a memoir; let pulse + papers + production projects carry proof
- **Featured vs full list** — spotlight top 3–4; keep the rest filterable (see `INSPIRATION.md` Tier 1)

**Skip:**
- Forking the layout wholesale — you'd lose terminal/pulse identity; borrow structure only

### 3. Lee Robinson — engineer / writer

| | |
|---|---|
| **Live** | [leerob.com](https://leerob.com/) |
| **Legacy blog** | [leerob.io](https://github.com/leerob/leerob.io) (open source) |
| **Awards** | Industry influence > badges; canonical “Vercel stack done right” reference |

**Why it's legendary:** Portfolio doubles as **writing platform**. Blog posts rank, get cited by AI tools, and prove depth. Site is fast, simple, and production-shaped (SSR, edge, live widgets in older versions).

**Steal for Tejas:**

- **Performance as brand** — fast LCP, no scroll-jank; recruiters on slow VPNs notice
- **Long-form depth elsewhere** — COLM poster + arXiv + case study routes (see inspiration backlog) mirror his “notes/blog” strategy

**Skip:**
- Pivoting to blogger-first if writing isn't your main channel yet — optional `/notes` later, not required for hire

### 4. Josh Comeau — design engineer / educator

| | |
|---|---|
| **Live** | [joshwcomeau.com](https://www.joshwcomeau.com/) |
| **Guide** | [Building an Effective Dev Portfolio](https://www.joshwcomeau.com/effective-portfolio/) (free ebook) |
| **Awards** | Teaching + craft reputation; portfolio is a product design case study |

**Why it's legendary:** Playful micro-interactions, typography, and **case studies that teach**. The ebook codifies what hiring managers actually scan for (2–5 projects, context, your role, outcome).

**Steal for Tejas:**
- **Case study format** — Problem → Constraints → Stack → Outcome → What I'd do next; fits Vantage, Trip Planner, Sci-FM
- **Interactive demos where they clarify** — your architecture flows and Streamlit embeds; avoid decoration-only motion
- **Ebook rules** — highlight reel, not archive; quality over quantity

**Skip:**
- CSS-heavy whimsy on every section — paper mode + terminal already give personality; don't add noise

### 5. Rauno Freiberg — design engineer (Vercel)

| | |
|---|---|
| **Live** | [rauno.me](https://rauno.me/) |
| **Awards** | Widely cited in “best dev portfolios”; OS/window metaphors influenced a generation of sites |

**Why it's legendary:** **Operating-system UI** as portfolio chrome — windows, menus, spatial hierarchy. Proves design-engineering at the highest level without a game engine.

**Steal for Tejas:**
- **Window metaphor** — your terminal + traffic lights + dock minimize are directly in this lineage; polish window chrome and keyboard shortcuts
- **Atmosphere with restraint** — one strong metaphor (terminal) beats five half-baked ones
- **Details recruiters feel** — focus states, sound opt-in, reduced-motion paths

**Skip:**
- Rebuilding a full fake OS — your terminal is enough; don't compete with Rauno on visual design alone

## What award juries actually reward

From Awwwards / FWA / Webby patterns across the sites above:

| Criterion | What winners do | Your equivalent |
|-----------|-----------------|-----------------|
| **Originality** | One memorable hook (3D world, OS UI, kinetic type) | Terminal + paper mode + live pulse |
| **Usability** | Still find contact + work on mobile | Keep packet, `/hire`, form, skip scroll-jacking |
| **Performance** | Fast despite motion; lazy-load heavy assets | Screenshot fallbacks, no auto-play embed weight |
| **Content** | Clear role, outcomes, not buzzwords | Experience impact lines, metric badges, COLM |
| **Dev craft** | Semantic HTML, a11y, reduced motion | `prefers-reduced-motion` on boot/marquee/sound |

You don't need a Webby to win recruiters — you need **clarity + one memorable hook + proof**.

## What NOT to copy from award sites

| Pattern | Why skip for your goals |
|---------|-------------------------|
| Full WebGL game world | Months of work; weak signal for ML/platform roles |
| Scroll hijacking / smooth-scroll libraries | Accessibility and mobile friction |
| Empty cinematic loader every visit | Once per session max (see inspiration doc) |
| Fake metrics / “100% satisfaction” | You have real pulse, papers, production users |
| 20-project masonry grid | Josh Comeau rule: 2–5 highlights, filters for the rest |
| Sound on by default | You already gate sound — keep it opt-in |
